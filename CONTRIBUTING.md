# Участие в проекте

[← На главную](README.md) · [Сборка](docs/building.md)

Для ошибки укажите модели телефона и часов, версии Android / Wear OS и DX, пару APK (Release или Compatible), шаги воспроизведения и ожидаемый результат. Добавьте относящиеся к ошибке события DX без личных данных.

Изменения удобно вносить отдельной веткой. В pull request объясните проблему, итоговое поведение и проверку. Для логики автоматизации, восстановления или владения звуком добавьте регрессионную проверку.

Перед отправкой:

```text
./gradlew :shared:testDebugUnitTest :wear:testDebugUnitTest lintRelease
```

Не включайте ключи подписи, пароли, local.properties, кэши, логи устройств и APK в Git. Готовые APK публикуются отдельными файлами релиза. Сохраняйте протокол совместимости и ресурс android_wear_capabilities при resource shrinking.

Лицензия собственного кода отдельно не выбрана; лицензии сторонних ресурсов перечислены в [NOTICE](NOTICE.md).
