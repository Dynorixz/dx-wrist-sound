# Установка DX • Wrist Sound

[← На главную](../README.md)

## Перед установкой

Нужны телефон Android 11+ и часы Wear OS 3+ с Google Play services и off-body датчиком. Сначала подключите часы к телефону через их системное приложение-компаньон. На обеих сторонах устанавливается DX с package `dev.dx.wristsound`, но APK разные.

Скачивайте APK из [официального релиза](https://github.com/Dynorixz/dx-wrist-sound/releases/tag/v1.2.4). Для новой установки используйте **Release**. Для обновления ранних локальных версий с прежним сертификатом — **Compatible**. [Сертификаты и обновления](release-signing.md).

## Телефон

Откройте Phone APK на телефоне и подтвердите установку выбранному установщику. Запустите DX и откройте **Настройки → Разрешения и доступы**. Выдайте доступ «Не беспокоить», уведомления и Bluetooth-доступ при запросе. На Xiaomi / Redmi / POCO также проверьте фоновый автозапуск и ограничения батареи.

## Часы через ADB

Установите Android SDK Platform Tools на компьютер. Подключите часы и компьютер к одной доступной Wi-Fi сети. На часах включите параметры разработчика и беспроводную отладку.

На главном экране отладки отображается **порт подключения**. В разделе «Сопряжение с помощью кода» — **другой порт и одноразовый код**. Не путайте их.

```text
adb pair WATCH_IP:PAIR_PORT
adb connect WATCH_IP:CONNECT_PORT
adb devices -l
adb -s WATCH_IP:CONNECT_PORT install -r DX-Wrist-Sound-Wear-1.2.4-release.apk
```

Первую команду выполняют для нового компьютера; код вводится интерактивно. Замените адреса реальными значениями с часов. Для Compatible замените имя APK.

Ключ `-s` адресует команду именно часам, когда телефон тоже подключён. `install -r` сохраняет данные при совместимой подписи. Если Android сообщает `INSTALL_FAILED_UPDATE_INCOMPATIBLE`, сначала проверьте сертификат и выбранную пару APK; не удаляйте приложение для обычного обновления.

## Включение автоматизации

1. Откройте DX на обоих устройствах.
2. На часах включите мониторинг; затем на телефоне включите автоматизацию и выберите часы.
3. Наденьте и разблокируйте часы один раз. Дождитесь подтверждённого состояния ношения.
4. Проверьте надевание и снятие. Базовые задержки: 3 и 5 секунд соответственно.
5. Системный звук часов настройте отдельно. DX 1.2.4 его сохраняет.

## Окно над циферблатом

На часах: **Разрешения → Окно поверх циферблата → Проверить доступ**. Фактический статус проверяется внутри DX.

На части Samsung системная страница выдачи доступа показывает «Недоступно». Если в DX написано «Разрешено», доступ уже действует. Если доступа нет, после сопряжения с ADB выполните:

```text
adb -s WATCH_IP:CONNECT_PORT shell appops set dev.dx.wristsound SYSTEM_ALERT_WINDOW allow
```

Вернитесь в DX: **Обновить статус → Проверить окно**. Приложение самостоятельно разрешение не выдаёт и AccessibilityService не использует.

## Голос или мелодия

На часах откройте **Оповещения**, включите предупреждение и выберите тип звука. Для речи нужен русский офлайн-голос системного TTS; установите его через раздел разрешений DX. Проверьте громкость медиа и тест выбранного оповещения.

Состояние «Телефон потерян» возникает только после подтверждённой непрерывной потери связи при надетых часах. Возврат связи отменяет ожидающую тревогу. Кнопка «Понятно» закрывает окно.

## После настройки

Проверьте [разрешения](permissions.md), фоновую работу и тест окна. Беспроводную отладку можно выключить. При проблемах откройте [диагностику](troubleshooting.md).
