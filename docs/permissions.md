# Разрешения и доступы

[← На главную](../README.md) · [Установка](installation.md)

DX показывает назначение и состояние доступов внутри приложения и ведёт к системным настройкам. Названия системных страниц зависят от версии Android / Wear OS.

## Телефон

| Доступ | Зачем | Где искать |
| --- | --- | --- |
| «Не беспокоить» / Notification policy | Android требует его для изменений звука, затрагивающих DND. | DX → Настройки → Разрешения и доступы. |
| Уведомления | Статус фоновой автоматизации и сообщения приложения. | Системные настройки уведомлений DX. |
| Подключение к устройствам / Bluetooth | Работа foreground service связанного устройства на соответствующих версиях Android. | Системный запрос или разрешения DX. |
| Фоновый автозапуск | Сохранение работы на прошивках, ограничивающих фоновые приложения. | На Xiaomi — настройки фонового автозапуска; путь зависит от HyperOS. |

## Часы

| Доступ | Зачем | Где искать |
| --- | --- | --- |
| Уведомления | Системное предупреждение о потере телефона. | DX → Разрешения → Уведомления. |
| Окно поверх циферблата | Показ отдельного окна с иллюстрацией и кнопкой. | DX → Разрешения → Окно поверх циферблата. |
| Работа без оптимизации батареи | Возможность восстановления фонового мониторинга. | DX → Разрешения → Работа ночью. |
| Датчик тела / здоровья | Только если прошивка отклоняет регистрацию off-body датчика без него. Приложение не считывает пульс. | Запрашивается при необходимости. |
| Русский офлайн-голос | Фраза «Вы забыли телефон» без сетевого TTS-голоса. | DX → Разрешения → Русский голос. |
| Доступ «Не беспокоить» | Может потребоваться системе для завершения восстановления звука после старых версий. | DX → Разрешения → Доступ «Не беспокоить». |

`WAKE_LOCK`, `MODIFY_AUDIO_SETTINGS`, разрешения foreground service и загрузки системы объявлены в манифестах; это не отдельные кнопки выдачи пользователем.

## ADB, если системный экран отсутствует

Для окна над циферблатом:

```text
adb -s WATCH_IP:CONNECT_PORT shell appops set dev.dx.wristsound SYSTEM_ALERT_WINDOW allow
```

Для notification policy на часах, если система его требует:

```text
adb -s WATCH_IP:CONNECT_PORT shell cmd notification allow_dnd dev.dx.wristsound
```

Команды выполняются **для часов** после [сопряжения](installation.md#часы-через-adb). После выдачи доступа вернитесь в приложение и обновите статус. DX не снимает PIN и не обходит системный DND.
